# Superstore Sales Dashboard

## Project Overview

This project presents an interactive **Power BI Sales Dashboard** built using the Superstore dataset. The dashboard transforms raw sales data into meaningful business insights through interactive visualizations, KPI tracking, and trend analysis. It helps users understand sales performance, profitability, customer behavior, and regional performance to support data-driven decision-making.

The project demonstrates how Power BI can be used to clean, model, visualize, and analyze business data in a professional reporting environment.

---

## Project Objectives

The main objectives of this project are to:

* Analyze overall sales and profit performance.
* Track key business KPIs through interactive dashboards.
* Identify high-performing and underperforming regions.
* Evaluate product category and sub-category performance.
* Analyze customer purchasing behavior.
* Monitor sales trends over time.
* Support business decisions using data visualization.

---

## Dashboard Analysis

The dashboard provides a comprehensive view of business performance by combining multiple visualizations into a single interactive report.

Key areas covered include:

* Total Sales
* Total Profit
* Total Orders
* Sales Trend Analysis
* Regional Performance
* Category & Sub-Category Analysis
* Customer Analysis
* Product Performance
* Segment-wise Sales Analysis

Interactive slicers and filters allow users to explore the data dynamically.

---

## Key Performance Indicators (KPIs)

The dashboard highlights important business metrics such as:

* Total Sales
* Total Profit
* Total Quantity Sold
* Number of Orders
* Profit Margin
* Average Sales per Order

These KPIs provide a quick overview of overall business performance.
